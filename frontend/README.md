# BreatheWise AI

Atmospheric Lab frontend. Phase 1 is the application shell: routing, shared types, and the API boundary. Feature screens are not built yet.

## Run

```bash
cd frontend
npm install
npm run dev
```

Copy `.env.example` to `.env.local` if the API is not at `http://127.0.0.1:8000`.
